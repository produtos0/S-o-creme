# SÓ O CREME — PIZZBURG_GRILL

Landing page responsiva refinada para a SÓ O CREME — PIZZBURG_GRILL, usando somente as informações fornecidas.

## Atualizações da versão 3
- Redução de repetições de localização e textos.
- Hero mais limpo e focado no nome, avaliação, cidade e CTAs.
- Tipografia de títulos atualizada para Barlow Condensed.
- Textos corridos em DM Sans para melhor legibilidade.
- Seção "Como pedir" simplificada.
- Galeria sem texto técnico desnecessário.
- Mapa estilizado substituído por mapa real incorporado do Google Maps.
- CTA final mais direto, sem slogan inventado.
- Barra de ações rápidas mantida no mobile.
- Informações reais preservadas: endereço, telefone, avaliação, cardápio e formas de atendimento.

## Abrir
Abra `index.html` no navegador ou publique toda esta pasta mantendo a estrutura de arquivos.
